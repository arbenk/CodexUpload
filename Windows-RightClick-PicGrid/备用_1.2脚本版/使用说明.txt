PicGrid 简易拼图工具（Windows 10） v1.2
================================

本版按你的反馈做了精简：

1. 右键菜单只保留“拼图...”
   - 已删除旧版“拼图”快速入口。

2. 不再闪 PowerShell 窗口
   - 资源管理器右键通过 Windows Script Host 静默启动。
   - 正常使用时只会看到“拼图设置”窗口。

3. 适应方式改成二选一
   - 宽度自适应：同一行同高，宽度按图片比例变化。
   - 高度自适应：同一列同宽，高度按图片比例变化。

4. 新增分辨率倍率
   - 每次打开默认 0.50×。
   - 可直接点“0.5×”或“1.0×”。
   - 也可在倍率框中直接输入，例如 0.75、1.25、2.00。
   - 设置窗口会显示首张图片的缩放示例，以及预计最终输出分辨率。
   - 为了让宽/高自适应排版整齐，倍率是“基础倍率”：同尺寸图片会严格对应 0.5× / 1.0×；混合不同尺寸图片时，同一行或同一列会按比例统一基准尺寸。

安装 / 更新
-----------
直接双击：安装右键菜单.vbs

无需管理员权限。若安装过 v1.1，直接安装 v1.2 即可覆盖；旧的“拼图”菜单会被自动移除。

使用
----
1. 在 Windows 10 资源管理器中多选至少 2 张图片。
2. 右键 → “拼图...”
3. 设置：
   - 每排图片数
   - 宽度自适应 / 高度自适应
   - 分辨率倍率（默认 0.50×）
   - 图片间距、外边距
   - JPG / PNG
4. “预计输出”会实时显示最终分辨率。
5. 点击“开始拼图”。

输出文件
--------
保存在第一张图片所在文件夹，名称类似：
拼图_20260826_120000.jpg

图片顺序
--------
按文件名自然排序：1.jpg, 2.jpg, 3.jpg, 10.jpg

支持格式
--------
JPG / JPEG / JFIF / PNG / BMP / GIF / TIF / TIFF
暂不支持 WebP。

日志
----
%LOCALAPPDATA%\PicGrid\picgrid.log

卸载
----
双击：卸载右键菜单.vbs
