# PicGrid v1.3.2

适用于 Windows 10 的右键图片拼图工具。

此版本修复了卸载 v1.2 后，安装 v1.3 时可能出现“PicGrid.exe 生成失败（错误代码 1）”且无法继续安装的问题。

## 安装

v1.3.2 可以从完全卸载状态直接安装，不依赖 v1.2。

双击 `安装右键菜单.vbs`。安装器会自动选择：

1. 单实例 EXE 模式（优先）。
2. 如果当前 Windows 10 的系统 C# 编译器生成 EXE 失败，则自动切换到兼容稳定模式。

兼容稳定模式同样支持：

- 右键菜单只保留“拼图...”。
- 通过隐藏 Launcher 启动，不闪现 PowerShell 黑框。
- 宽度自适应和高度自适应。
- 默认 0.50 倍，可选择 0.5 倍、1.0 倍或手工输入倍率。
- 实时显示预计输出分辨率。
- 设置窗口主动置于前台并获取焦点。

## 日志

EXE 编译诊断日志（仅在排查问题时需要）：

```text
%LOCALAPPDATA%\PicGrid\compile.log
```

运行日志：

```text
%LOCALAPPDATA%\PicGrid\picgrid.log
```

## 卸载

双击根目录中的 `卸载右键菜单.vbs`。
