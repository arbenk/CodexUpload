# CodexUpload

这是一个利用codex制作并上传的一些我的工具存档，多数用于图像设计工具。

## 项目与能力

| 项目 | 简要能力描述 |
| --- | --- |
| Photoshop 字体导航（CEP） | 扫描 Photoshop 文档中的文字图层和混合字体区间，定位字体使用位置，并批量替换为已安装字体。 |
| PSD 字体批量查询 | 无需启动 Photoshop 即可批量读取 PSD/PSB 的文字图层字体信息，标记缺失字体，并生成 TXT/HTML 报告。 |
| PS2020 系统字体隐藏工具 | 为 Photoshop 2020 提供系统字体隐藏与恢复相关的 Windows 菜单脚本。 |
| STL Six Views Renderer | 在 Blender 中为单个或批量 STL 渲染前、后、左、右、顶、底六视图，并可合并生成图集。 |
| Drop to Ground & Align | 在 Blender 中将物体放置到地面，并提供外贴合、内码齐、轴对齐和分散对齐工具。 |
| FlatFab Plate Flatten | 面向 Blender 板材设计，提供板厚实体化、参数化插口与刀线、板件展平排版，以及 SVG/DXF/PDF 和 UV 工作流。 |
| 长图浏览器 | 用于浏览和查看长图文件的独立 Windows 工具。 |
