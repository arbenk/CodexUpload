# PSD 字体批量查询

独立 Windows 软件，后台读取 PSD/PSB 的文字图层元数据并生成字体报告，不需要启动 Photoshop。

## 当前功能

- PSD/PSB 多选文件列表。
- 支持直接拖入 PSD/PSB 文件。
- 手动预览文件列表中的全部文件。
- 自动预览当前单选或多选的文件。
- 强制刷新会清理文件缓存并重新扫描已安装字体。
- 可复制的纯文本字体预览。
- 简体中文、繁体中文、英文顺序选择已安装字体名称。
- 缺失字体标记为 `【未安装】`。
- TXT/HTML 输出、自定义目录及文件名；HTML 使用单一汇总表格。
- 默认输出当前文件列表；勾选“追加”时保留旧记录，并追加新文件或更新同路径文件。
- 元数据优先读取，跳过图层像素和合成图像数据。
- 扩展功能提供已安装字体扫描、顺序置顶、可恢复删除、还原和临时回收站清理。

## 运行

```powershell
python main.py
```

## 构建

运行 `build.ps1`，生成独立程序目录和 Inno Setup 安装包。
