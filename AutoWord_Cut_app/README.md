# 自动切字工具 v0.5

## 手动画框与快速分割

- 点击“手动画字符框”或按 `N` 后，画布光标变成十字。按住鼠标左键拖出矩形，松开左键即可建立一个独立字框。
- 鼠标按住拖动画框期间，可随时按下或松开组合键：`Ctrl + 滚轮`调整左右列数，`Shift + 滚轮`调整上下行数，`Ctrl+Shift + 滚轮`同时调整行数和列数。
- 已经得到的分段会保持；鼠标仍按住时，松开某个组合键再重新按下，仍可继续调整对应方向。
- 鼠标松开后，如果 Ctrl 或 Shift 仍按住，预览会继续保留；两个键都松开时才正式生成全部独立字框。
- 分割过程中使用青色虚线预览；组合键控制分割时滚轮不缩放画面。按 `Esc` 可取消本次画框。
- 分割生成后，每个小框都能单独移动、缩放和删除，不会联动其他框。
- “撤销 / 重做”可恢复误删、误移、缩放、手动画框、分割、重新编号和收缩操作；快捷键为 `Ctrl+Z` / `Ctrl+Y`（也可用 `Ctrl+Shift+Z` 重做）。一次完整拖动只记作一步，最多保留最近 100 步；打开另一张原图时会清空旧图历史。
- 多选多个字符框后，拖动其中一个框的某条边，会让所有选中框的同一条边按相同距离同步调整；拖左边同步左边，拖上边同步上边，其他边同理。
- 选择一个或多个字符框后点击“收缩选中字框到墨迹”，程序会判断明底黑字或暗底亮字，并将每个框分别收缩到实际字形的最外缘。如果原框某条边切中了连续笔画，程序会沿该连通区域向框外追踪并扩展到笔画的真正边缘；框外不相连的邻字和污点不会被吸入。随后使用正方形补边导出时，紧边界字形会重新居中，减少上偏、下偏和多余空白。
- “收缩去杂阈值”范围为 `0.00%–10000.00%`，默认 `0.00%`。例如设为 `5.00%` 时，会忽略宽度低于字框宽度 5%、或高度低于字框高度 5% 的独立连通细线，并忽略面积低于字框总面积 0.05% 的独立小块。它只影响收缩边界的判断，不会擦除导出图像；与主体字形相连的笔画不会被忽略。阈值过高导致没有有效墨迹时，原字框保持不变。

工作流分为“自动检测、字框审核与 OCR、最终导出”三个阶段。

## 使用方法

1. 双击 `启动自动切字工具.bat`。
2. 点击“打开原图”。
3. 选择处理模式并点击“自动切字”：
   - 普通白底黑字大字：选择“主体大字”。
   - 黑底白字、横向密集碑刻：选择“碑刻密集横排（白字黑底）”。
4. 根据预览调整：
   - 忽略左侧：排除左侧题跋，默认 15%。
   - 裁图留白：默认 12%。
   - 字符合并：字被拆开时调大，相邻字粘连时调小。
5. 人工校正：
   - 拖动框内部：移动字符框。
   - 拖动框的边缘或四角：调整大小。
   - 鼠标滚轮：放大或缩小画面。
   - “显示字符编号”和“显示字符名称”可分别开关，也可以同时显示；`H` 只切换数字编号。红框和控制点始终可继续编辑。
   - `N` 或“手动画字符框”：进入十字光标模式，在画布上拖动建立新框。
   - `Delete` 或“删除选中框”：删除误检框。
   - 框修正后点击“按当前模式重新编号”。普通模式按竖排编号，密集横排模式按行编号。
6. 字框较多时，点击“导出审核图”，在 `review` 文件夹中删除错误图片，再点击“同步审核结果”并选择审核包。
7. 审核后可点击“本地 OCR 初标”，程序会离线逐框猜字并写入字名内容；`□` 表示未识别。
   - OCR 完成并显示名称后，可直接点击右侧字符框顶部的名称，在弹窗中修改该字，无需再到左侧字名列表中查找顺序。
   - EXE 版不内置 OCR 引擎和模型。第一次点击 OCR 时，程序会询问是否下载约 35 MB 的可选组件，校验 SHA-256 后安装到 `%LOCALAPPDATA%\AutoWord_Cut_app\ocr`；以后离线使用，不会重复下载。
   - 尚未配置在线发布地址时，也可以在首次提示中选择本地的 `ocr-component-windows-x64-py314.zip` 安装。OCR 下载或安装失败不会影响切字、编辑和导出功能。
8. 按需要选择导出后处理：
   - “导出为纯黑白图”：先校正背景，再自动阈值化为黑、白两色；白字黑底模式会自动转成白底黑字。
   - “阈值微调”：正值减少浅色噪点，负值保留更多浅墨。
   - “干净化”：仅在纯黑白导出时启用，并按“黑色”后“白色”的顺序执行。
   - “黑色净化”：先用黑色填补黑色字形内部的小白块。
   - “白色净化”：再用白色清除连续白色背景中的小黑块。
   - 两项强度均最低为 0.00%，不设置人为上限，可输入不同数值并保留两位小数。数值与可处理连通区域的面积上限线性对应。
   - “居中补边为正方形”：不拉伸字形，使用补边变成正方形。
   - “统一尺寸”：可保持原像素，或输出 128、224、256、512 方形图。
9. 点击“最终导出”。导出前程序也会自动重新编号。

## 超长横卷与不规则字距

对于超长横卷，普通自动检测会因整体缩小而丢失细小文字。可使用“标准框引导检测”：

1. 打开原图后点击“手动画字符框”，直接框住一个清晰且大小具有代表性的普通单字；标准框不必位于第一字。
2. “引导检测字数”填写已知总字数，例如《老子授经图卷》填写 `1563`。
3. 点击“按选中标准框引导检测”。标准框只提供单字的大致宽高，程序会在保留文字细节的分辨率上查找每个实际墨迹中心，不使用固定行距或列距。
4. 对《老子授经图卷》建议先尝试约 `90×90` 至 `110×110` 像素的标准框。应选择普通字，不要选择特别宽、特别高或笔画极少的字。
5. 生成后仍可逐框移动、缩放、删除，并可导出审核图进一步筛除错误框。

### 规则网格模式

如果原作整体接近规则字格，也可以在“处理模式”中选择“标准框规则网格（保留空白）”：

1. 单锚点：新增一个字符框，将它放在最右上角第一个字格，并调整到一个完整格子的大小。
2. 双锚点：也可以再新增一个框，放在文字区域最左上角的字格。生成时同时选中右上、左上两个框，网格就只分布在两个锚点之间；两个锚点可分别缩放，中间各列的框尺寸会平滑过渡。这样可以避开画卷中的图案区域。
3. 填写“目标/网格总数”“网格每列格数”，并按需要调整横向、纵向步距；100% 表示步距等于标准框宽度或高度。双锚点模式的横向位置由两个锚点自动确定。
4. 点击“自动切字”生成从右向左、每列从上到下的规则网格。
5. 网格中的空白位置也会保留为字符框；在右侧选中空白框后按 Delete 即可删除，然后可重新编号。
6. 生成后的每个格子都是独立字符框：拖动框内只移动当前格，拖动某一条边只改变当前格的局部宽高，不会带动同一行、同一列或其他格子。

### 文字区域动态切字（推荐用于不规则写经）

1. 在“处理模式”中选择“文字区域动态切字（竖排）”。
2. 新增一个字符框，并把它拉大为文字区域框，只包围需要处理的竖排文字，尽量排除画面、题跋和大面积空白。
3. “目标/网格总数”填写这个区域内预计包含的文字数量；已知全文为 1563 字且区域包含全文时填写 `1563`。
4. 保持文字区域框为唯一选中框，点击“自动切字”。程序先检测竖列，再在每列内部独立寻找字符中心和局部墨迹边界，不要求各列或各字上下对齐。
5. “裁图留白”会应用到动态生成的字符框。生成后仍可逐框移动、缩放、删除，并可导出审核图。
6. 动态检测完成后会自动消除字符框之间的面积重叠：相邻框沿中心中线收缩边缘，可以相互接触，但不会互相覆盖。

预览区可按住鼠标中键拖动平移画面；滚轮继续用于缩放，左键继续用于选择、移动和调整字符框。

## 多批字符集去重

1. 点击“字符集去重与质量审核”，选择包含多次最终导出结果的总文件夹；程序会递归读取各结果中的 `boxes.json` 和 `crops`。
2. 所有切字图按文字名称分组显示；每个文字默认选择质量分较高的一张。
   - 候选格使用紧凑的 `62×62` 完整等比例缩略图，每行最多显示 14 张；来源文件夹、完整路径和质量分放在鼠标悬停提示中，不会挤占缩略图空间。
3. 点击同组的另一张图会切换保留项；再次点击当前选中图会取消该文字的选择。
4. 点击“处理并另存选中字符”，程序只复制最终选中的图片到新的“去重字符集”文件夹，并生成 `deduplicate_manifest.json`；原来的多批结果不会被修改。

## 审核包与工程

- “导出审核图”始终使用 `0001.png` 形式的稳定编号，不受最终文件命名设置影响。

## EXE 与可选 OCR 组件

- 主程序打包 PySide6、NumPy 和 OpenCV，但排除 RapidOCR、ONNX Runtime 与 OCR 模型。
- `ocr_component_manifest.json` 保存组件版本、下载地址、大小和 SHA-256。将组件 ZIP 发布到 HTTPS 地址后，填写 `download_url` 并重新打包主程序即可启用在线按需下载。
- `python build_ocr_component.py 输出路径.zip` 可从当前 Python 3.14 环境重新生成匹配的 Windows x64 OCR 组件包。
- 可选择把审核图居中补边为 512×512；审核图仅用于筛选，最终图始终重新从高清原图裁取。
- 在资源管理器中删除误检审核图后，使用“同步审核结果”删除对应字符框；程序会先显示数量并要求确认。
- “保存工程”记录原图路径、字符框、顺序和已有字名；“载入工程”可在关闭程序后恢复。
- 工程依赖原始图片路径，请不要在保存工程后移动或重命名原图。

## 本地 OCR

- RapidOCR 和 ONNX Runtime 均在本机运行，不上传原图或单字裁图。
- OCR 只负责初步标记；书法、碑刻、异体字和残字必须人工复核。
- 推荐先完成审核、删除错误框，再运行 OCR，可减少无效识别并节省时间。

## 按字名命名

- 勾选“按单字名称命名”，按当前字符框编号顺序粘贴文字，或导入 UTF-8/GB18030 编码的 TXT。
- 可以连续粘贴，也可以一行输入一个字；空格与换行会被忽略。
- 字名数量必须与字符框数量完全一致，程序才会导出，避免训练标签错位。
- 同一个字第一次保存为 `字.png`，随后依次保存为 `字02.png`、`字03.png`。
- 勾选“显示字符名称”后，框上会实时显示最终文件名（不含 `.png`）；它与数字编号相互独立，可以同时显示。
- “导出文件夹名”可以在每次导出前修改，不再固定使用原图名称。
- 未勾选时继续使用 `0001.png`、`0002.png` 的数字文件名。

## 输出

- `preview_numbered.png`：带编号字符框的预览。
- `boxes.json`：字符框坐标及阅读顺序。
- `crops/0001.png...`：原始彩色单字裁图。

当前版本优先处理竖排、从右到左阅读的主体大字，支持人工增删、移动和缩放字符框。文字命名将在下一阶段加入。

v0.3 起，编辑框采用细线和半透明颜色，编号标签缩小，减少对原图内容的遮挡。

v0.4 新增“碑刻密集横排（白字黑底）”模式：自动定位黑色正文面板、检测横行并逐字分框。
