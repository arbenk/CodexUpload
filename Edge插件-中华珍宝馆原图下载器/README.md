# 中华珍宝馆 100% 原图下载器 v0.1.0

## 安装

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧或右上角的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本文件夹：`Edge插件-中华珍宝馆原图下载器`。
5. 建议将扩展固定到工具栏。

## 使用

1. 打开 `https://g2.ltfc.net/view/...` 形式的中华珍宝馆作品页面。
2. 等待大图查看器加载完成。
3. 点击工具栏中的“中华珍宝馆 100% 原图下载器”。
4. 在打开的下载器页面选择需要的图片及 PNG/JPEG 格式。
5. 点击“下载所选原图”，保持下载器页面开启，直至显示完成。

插件会读取页面公开的大图元数据，下载最高层切片并在本机浏览器中拼接。图片不会上传到第三方服务。

## 当前限制

- 网站若修改页面数据结构或切片签名规则，扩展可能需要升级。
- 极端超大图片可能超过浏览器 Canvas 的尺寸或内存限制；当前安全限制为单边不超过 32767 像素、总像素不超过 1.3 亿。
- 多图任务会逐张处理并分别下载，以控制内存占用。
