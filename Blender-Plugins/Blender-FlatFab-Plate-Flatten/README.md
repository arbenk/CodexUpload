# FlatFab Plate Flatten

当前版本：**1.8.2**

## 1.8.2 修复

- 边插的点齿模式新增“边缘距离”，默认 50 mm（与默认齿宽一致），可调整到 0。
- 板材两端距离不再作为齿间均匀间隙参与“齿宽不能超过间隙”的判断。
- 单个点齿始终在有效贴合边居中，仅要求齿宽不超过边长；例如 100 mm 边可正常生成一个 50 mm 点齿，不再被错误限制为约 33 mm。

## 1.8.1 修复

- h 扣插改为以两侧插槽的内部末端作为共同中心点；根部与插舌长度不相等时，两侧仍能正确互补咬合，不再因分别居中产生装配重叠。
- h 扣数量排布改用共同中心两侧的真实最大占用范围，并继续支持整体翻转插入方向。

## 1.8.0 新增

- 新增小写名称的“h 扣插”：自动识别两块板面垂直、公共边贴合但板面不穿插的板件。
- 可设置插舌长度、总体长度和 h 扣数量；扣体宽度自动为对方板厚的 2 倍。
- 新增“翻转扣插方向”，可整体交换两侧扣舌朝向和插入方向。
- 外侧转角和插舌自由端默认生成 1 mm 倒角，可调整或设为 0。
- 每组两侧扣件共用同一个“插槽内部末端”中心点；即使插舌与连接根部采用 1/3、2/3 等非等长比例，翻转后的两侧轮廓仍能准确咬合和对齐。

FlatFab 面向 Blender 板材设计、实体化板厚、参数化插口、刀线、拼板、SVG/DXF/PDF 与整版 UV 回贴工作流。

## 1.7.4 新增与修复

- 新增“批量生成选中板件的边插”：自动检查选中板件的两两组合，只为实际符合边贴面关系的组合生成连接。
- 已存在的边插连接会自动跳过，并汇总新增、重复及不符合条件的组合数量。
- 连接记录列表默认折叠，避免大量连接占满侧栏；“删除全部连接定义”保持在折叠区外，随时可用。
- 修正部分方向的箱形布尔辅助体成为左手坐标系、法线整体反转的问题；Blender 5.2 Exact Boolean 现在能够真实切出箱体各侧插槽。

## 1.7.3 修复

- 贯穿片或十字插板在自身板面内倾斜时，分别计算接收板顶面、底面的真实交线。
- 布尔切刀采用两侧交线的最长覆盖范围，不再只按接收板中心面交线生成。
- 消除厚板斜边端部可能留下的三角形残角，同时保留十字插中间的 1/2 分界。

## 1.7.2 新增

- 边插新增“允许板面边界开放插槽”，默认开启。
- 插入板边与接收板轮廓边界贴合时，仍会生成插齿，并在接收板边缘生成开放式插槽。
- 关闭该选项可恢复只接受板面内部接触线的严格识别方式。

## 1.7.1 修复

- 修正箱形连接辅助体六个面全部反向的问题。在 Blender 5.2 Exact Boolean 中，旧辅助体可能只在板材表面留下分割拓扑而不真正切除体积。
- 边插插槽、十字插两侧半槽和贯穿槽现在会产生真实的体积切除。
- 统一校正棱柱辅助体的轮廓方向，提升矩形与楔形边连接在不同板面法线、选择顺序下的稳定性。
- 创建辅助体时验证退化尺寸、非正交轴和无效轮廓，避免生成不可用的 Boolean。
- 已在 Blender 5.2.0 LTS 验证 90°/斜角连接、反向选择、多区间孔洞、公差、重算、刀线及 SVG/DXF/PDF。

## 推荐流程

1. 面片建模
2. 在 FlatFab 中快速设置场景毫米/厘米
3. 给选中板件添加或更新 Solidify 板厚
4. 搭建板件空间关系
5. 生成 / 重算参数化插口
6. 1:1 生成板件刀线
7. 排版 / 方形拼板
8. 导出 SVG / DXF / PDF
9. 更新整版 `FlatFab_Layout` UV
10. SVG 分支制作实物；贴图分支在 PS 中绘制后回 Blender 查看效果

## 1.7.0 本轮重点

### ① 单位 / 实体化

顶部新增制造前置区：

- **毫米 (mm)**：场景设为 METRIC，`scale_length = 0.001`，长度显示为 MILLIMETERS。
- **厘米 (cm)**：场景设为 METRIC，`scale_length = 0.01`，长度显示为 CENTIMETERS。
- **板厚**默认 `5 mm`。
- **实体化偏移**只能选择 `+1` 或 `-1`。
- “给选中板件添加 / 更新实体化”会处理所有选中 Mesh：没有 Solidify 就新增，已有 Solidify 就更新厚度和 offset。
- 对有对象缩放的板件，FlatFab 会按板面法线方向补偿对象缩放，使输入的 mm 尽量对应实际世界板厚。

### ② 参数化插口 / 插槽

现在选择两个板件即可，**不再使用活动对象来表达 A/B**。

#### 边插

角色自动识别：

- 哪一块板存在“实体边贴到另一块板实体表面”的关系，哪一块就是插齿方；
- 被贴到表面的板就是插槽方；
- 双向检测会比较贴面距离、接触线有效长度以及接触点离接收板边界的余量；
- 如果检测结果更像“边-边贴合”，边插会拒绝误生成，并提示使用“边连接”。

边插接触线不再使用接收板包围盒长度，而是把插入边投影到接收板真实二维轮廓后做裁切，因此面片 + Solidify、凹轮廓和孔洞条件下更稳定。

齿仍支持：平均齿 / 点齿 / 标记齿。齿深自动为接收板厚，公差只放大槽。

#### 十字插

删除“半齿段数”参数。

每一个真实重叠区间固定处理为：

- 区间均分为两个 1/2；
- 第一半从一块板切除，第二半从另一块板切除；
- 两块板的半齿刚好互补；
- “反转半齿 / 进入方向”交换两块板承担的半区间；
- 如果一块板的整个重叠区间确实被包在另一块板内部，才会为外层板生成滑入导缝；
- 凹轮廓/孔洞造成的分离区间不会被错误用一条长导缝连起来。

斜交仍按：

`投影槽宽 = 对方板厚 / sin(两板夹角)`

处理板厚投影。

#### 边连接

修复接收板某些情况下没有真正被切掉的问题：

- 每一段都明确生成一方 UNION 齿 + 另一方 DIFFERENCE 槽；
- 槽切刀会略微跨过共同接缝，确保与接收板产生真实体积相交，而不是只在边界共面接触；
- A/B 两侧都会交替成为接收板，所以两边都会实际开槽；
- 保留矩形锯齿、楔形/拼图齿、自定义深度与公差。

#### 贯穿

贯穿改用多区间裁切：

- 求两板中心面交线；
- 分别与两块板**全部二维边界环**裁切；
- 使用 even/odd 规则处理外轮廓、孔洞、凹多边形和分离区域；
- 得到多个独立共同区间时，分别生成多个贯穿槽，不再只取最长的一段；
- 默认按交线支持长度和板面范围自动选择较局部的板作为贯穿片；
- 如果你的装配意图相反，可勾选“反转贯穿方”。

### 多区间 polygon clipping

1.7.0 的交线裁切保留所有边界环，而不是只保留最大外轮廓。

例如一条交线穿过：

`实体区域 → 孔洞 → 实体区域`

会得到两个独立有效区间。十字插和贯穿都会分别处理这两个区间，不会跨孔补成一条连续槽。

这套裁切不依赖外部 Python 几何库，直接随 Blender Extension 安装。

## 公差

默认 `0.2 mm`，仍然遵守：

- 公差只影响槽 / 孔，不缩小或放大插齿；
- “仅宽度公差”开启时，不再增加用于容纳另一块板材厚度的方向。

## 非破坏与重算

连接继续使用 FlatFab 自己的隐藏辅助体与 Boolean 修改器：

- 原始面片不被直接编辑；
- Solidify 仍可继续参数化修改；
- 移动板件后可以“重算”连接；
- “清几何”只移除 FlatFab 连接布尔和辅助体，保留连接定义；
- 重新生成刀线时，只要启用“包含修改器结果”，新插齿/插槽会进入最终刀线。

## 后续工作流

原有功能全部保留：

- 1:1 展平
- ±90° / 镜像 / 锁组
- 常规排版 / 方形拼板
- SVG / DXF / PDF
- `FlatFab_Layout` 整版 UV
- 输出管理

安装：Blender 4.2+ → `编辑 > 偏好设置 > 扩展 > 从磁盘安装` → 选择 ZIP。安装后在 3D View 按 `N`，打开 **制造 > FlatFab 板件制造**。
