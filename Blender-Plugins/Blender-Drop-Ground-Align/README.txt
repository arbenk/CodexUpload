Drop to Ground & Align
Blender Extension v1.7.1
适用版本：Blender 4.2+

========================================
插件功能
========================================

1. 放置地面
- 将选中物体的世界空间最低点移动到 Z = 0。
- 顶端放置：将选中物体的世界空间最高点移动到 Z = 0。

2. 外贴合
- 以最后选中的激活物体作为目标。
- 支持 X / Y / Z。
- 支持全局坐标 / 激活物体局部坐标。
- 将其他物体移动到目标物体外侧，边界间距为 0。

3. 内码齐
- 自动判断移动物体位于目标物体哪一侧。
- 将移动物体远端边界对齐到目标物体最近端边界。

4. 轴对齐
- 以最后选中的激活物体作为目标。
- 可选择质心点、中心点或原点作为对齐基准。
- 默认使用中心点，即世界空间包围盒的宽度中心。
- 使用 X / Y / Z 按钮沿对应世界轴对齐。

5. 分散对齐
- 自动寻找中心距离最远的两个选中物体。
- 以两者连线作为分散轴。
- 可选择世界 X / Y / Z 轴限制分散方向；默认全部不选，保持自动连线模式。
- 支持手动输入间隙。
- “均匀”模式固定首尾物体并平均排列中间物体。
- 空间不足时自动使用包围盒中心点等距排列。

========================================
Blender 4.2 Extension 安装方法
========================================

1. 打开 Blender 4.2。
2. 编辑 > 偏好设置 > Get Extensions / 扩展。
3. 点击右上角菜单。
4. 选择 “Install from Disk / 从磁盘安装”。
5. 选择整个 ZIP：
   Blender-Drop-Ground-Align.zip
6. 安装并启用。
7. 3D 视图按 N，进入“工具”标签。
8. 找到“放置 & 对齐”。
